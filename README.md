# 🐜 Симулятор муравья

**Симулятор муравья** — настольное приложение на C# с графическим интерфейсом WPF, позволяющее моделировать движение муравья по клеточному полю согласно заданным пользователем правилам.

Проект реализует механику клеточного автомата: поведение муравья зависит от цвета клетки, на которой он находится. Пользователь может самостоятельно настраивать правила движения, поворота и изменения цвета клеток.

## 📌 Возможности

- **Настройка игрового поля** — создание поля с произвольной шириной и высотой.
- **Ручное редактирование** — изменение цвета отдельных клеток нажатием мыши.
- **Случайная генерация** — заполнение поля случайными чёрными клетками с заданной вероятностью.
- **Настройка правил** — отдельные наборы действий для белых и чёрных клеток.
- **Управление направлением** — поворот налево, направо, разворот на 180° или сохранение направления.
- **Управление движением** — возможность двигаться вперёд или оставаться на месте.
- **Изменение цвета клеток** — сохранение текущего цвета, окрашивание в чёрный или белый цвет, случайное изменение цвета.
- **Управление симуляцией** — запуск, пауза, остановка, выполнение одного шага и сброс.
- **Настройка скорости** — изменение интервала выполнения шагов.
- **Отслеживание выполнения** — отображение количества выполненных шагов и текущего состояния симуляции.
- **Контроль границ** — автоматическая остановка при попытке выйти за пределы игрового поля.

### Основные компоненты

- **Models** — модели муравья, клеток, направлений и правил поведения.
- **Services** — логика создания игрового поля и выполнения симуляции.
- **ViewModels** — управление состоянием приложения и взаимодействием между интерфейсом и логикой.
- **Controls** — пользовательские элементы управления, включая отрисовку игрового поля.
- **Resources** — ресурсы приложения.

## 🚀 Запуск проекта

### Требования

- Windows.
- Visual Studio 2022 или новее с поддержкой .NET 10.
- .NET 10 SDK.
- Компонент разработки классических приложений .NET.

1. Клонируйте репозиторий:

```bash
git clone https://github.com/MatveyDevs/AntSimulator.git
```

2. Перейдите в папку проекта:

```bash
cd AntSimulator
```

3. Откройте решение `AntSimulator.sln` в Visual Studio.

4. Выполните сборку проекта.

5. Запустите приложение клавишей `F5`.

## 🎮 Принцип работы

Муравей перемещается по клеточному полю и выполняет действия в зависимости от цвета текущей клетки.

Для каждого цвета можно настроить три параметра:

1. **Поворот** — определяет изменение направления движения.
2. **Изменение цвета** — определяет, каким станет цвет текущей клетки.
3. **Движение** — определяет, будет ли муравей перемещаться вперёд или останется на месте.

Например, для белой клетки можно задать поворот направо, окрашивание в чёрный цвет и движение вперёд. Для чёрной клетки — поворот налево, окрашивание в белый цвет и движение вперёд.

Симуляция выполняется последовательно, шаг за шагом, пока пользователь не остановит её или муравей не достигнет границы поля.
